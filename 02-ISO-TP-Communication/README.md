# ISO-TP Communication

## Overview
This folder contains Arduino/C++ examples exploring ISO-TP (ISO 15765-2) communication over CAN bus.

ISO-TP enables the transmission of data payloads that exceed the capacity of a single Classical CAN frame.

## Project Description
The examples explore:
- CAN interface configuration
- ISO-TP message transmission
- Receiving data through callbacks
- Handling communication payloads
- Serial monitoring of received data

## Technologies
- Arduino / C++
- FlexCAN_T4
- ISO-TP
- CAN Bus

## Project Files
- `isotp_example_send_receive.ino` — Main communication example.

## Notes
This is an experimental code example. Hardware testing and successful communication have not been independently verified.
