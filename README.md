# CAN Bus Communication — Arduino and ArduPilot

## Overview

This project contains experimental scripts exploring CAN bus communication between Arduino and ArduPilot systems.

## Communication Examples

**ArduPilot to Arduino**
- `canwrite.lua` — CAN message transmission
- `canflexcan.ino` — CAN message reception

**Arduino to ArduPilot**
- `canflexcansend.ino` — CAN transmission example
- `canread.lua` — CAN message reception

## Technologies
- Arduino / C++
- Lua
- ArduPilot
- FlexCAN_T4
- CAN Bus

## Notes
These scripts are experimental examples. Complete bidirectional communication and hardware validation have not yet been documented. Original code sources and any modifications should be credited where applicable.
